    What do area, shape, distance and direction mean?
    Area
    How much space a place takes up.
    Shape
    The outline of a place, like the curve of a coastline.
    Distance
    How far apart two places are.
    Direction
    Which way one place is from another, like north or southeast.

    You can’t flatten a ball without stretching or tearing it, so every flat map changes at least one of these.

    About Map Projection Lab

    A projection is the math that turns the round Earth into a flat map. This lab draws the same world, and the same circles, in nine projections, and slides every point from one map to the next so you can see what each projection stretches.

    How it works

    • Country boundaries come from the World Countries (Generalized) layer in ArcGIS Living Atlas, then simplified in the browser with the ArcGIS generalize operator.
    • Every circle is a true geodesic circle with a 500-mile radius, made with the ArcGIS geodesic buffer operator. On the real Earth they are all exactly the same size.
    • Every point is projected into each map by the ArcGIS projection engine, using the same projection definitions as ArcGIS Pro and ArcGIS Online.
    • To morph, each point slides in a straight line from where it sits on one map to where it sits on the next.
    • Real areas are measured on the curved Earth with the ArcGIS geodetic area operator. Map areas are measured flat, on the projected map.

    Keyboard

    • 1 to 9: choose a projection.
    • Select the map, then use the arrow keys to move the measuring circle. Hold Shift to move it further.
    • The tour can be paused at any time. If your device is set to reduce motion, maps switch without animating.
